# Практика 2: Визуализатор графа зависимостей (Вариант 21)

## Общее описание
Инструмент визуализации графа зависимостей для менеджера пакетов. 
Этап 1: минимальный прототип с конфигурацией.

## Функции и настройки
Программа принимает путь к JSON-файлу конфигурации через аргумент `--config`.
Файл содержит следующие параметры:
- `package_name` — имя анализируемого пакета.
- `repo_url` — URL-адрес репозитория.
- `test_mode` — режим работы с тестовым репозиторием (true/false).
- `package_version` — версия пакета.
- `max_depth` — максимальная глубина анализа зависимостей.

## Запуск
```bash
python src/main.py --config configs/config.json
